# Token-Cluster Interaction (TCI)

**Predicting When Approximate Scoring Fails in Multi-Vector Retrieval**

*Anonymous — CIKM 2026 Submission*

---

## Overview

TCI is a training-free intermediate scoring method for multi-vector retrieval that clusters each document's token embeddings via k-means at index time and approximates MaxSim through centroid interaction. The accompanying **E/M ratio** diagnostic predicts — from raw embeddings alone — whether TCI will help on a given corpus.

### Key Results
- **21/21** correct E/M predictions across 4 architectures (ColBERTv2, XTR, ColPali, ColQwen2)
- **12/12** statistically significant improvements on adequately-powered datasets
- **5–20×** fewer Chamfer evaluations at equal recall
- Validated across **17 datasets**, **9 domains**, and **2 modalities** (text + visual)

## Quick Start

### 1. Encode a dataset
```bash
# Text (ColBERTv2)
python scripts/encode_multi_model.py --dataset scifact --model colbertv2

# Visual (ColPali)
python scripts/encode_colpali.py --dataset vidore/vidore_v3_finance_en
```

### 2. Compute E/M ratio (should you use TCI?)
```bash
python scripts/run_margin_analysis.py --embeddings-dir data/scifact_colbertv2
```
If ρ > 1.3 → deploy TCI. If ρ < 1.0 → TCI is unnecessary.

### 3. Run TCI pipeline with significance testing
```bash
python scripts/run_significance.py --embeddings-dir data/scifact_colbertv2 --tci-k 32
```

### 4. Validate theoretical bound
```bash
python scripts/run_theory_validation.py --embeddings-dir data/scifact_colbertv2
```

## Scripts

### `run_significance.py`
Full retrieval pipeline: FDE → TCI → Chamfer reranking with paired Wilcoxon signed-rank tests.
```bash
python scripts/run_significance.py \
  --embeddings-dir data/scifact_colbertv2 \
  --tci-k 32 \
  --fde-candidates 1000 \
  --rerank-budget 200
```

### `run_margin_analysis.py`
Computes E/M ratio (ρ), inversion rates, and scoring errors. No retrieval needed.
```bash
python scripts/run_margin_analysis.py --embeddings-dir data/scifact_colbertv2
```

### `run_baselines.py`
Compares TCI against 5 alternative intermediate scoring methods (PLAID-32, MeanPool, MaxPool, RandomSub, UniformSub).
```bash
python scripts/run_baselines.py --embeddings-dir data/scifact_colbertv2
```

### `run_kmeans_robustness.py`
Cluster quality analysis (silhouette scores) and k-means seed variance.
```bash
python scripts/run_kmeans_robustness.py --embeddings-dir data/scifact_colbertv2 --n-seeds 10
```

### `run_efficiency.py`
Wall-clock timing and iso-recall analysis.
```bash
python scripts/run_efficiency.py --embeddings-dir data/scifact_colbertv2
```

## Embedding Format

All scripts expect the following files in `--embeddings-dir`:
```
corpus_flat.npy      # (N_tokens, dim) float32 — all document tokens concatenated
corpus_lengths.npy   # (N_docs,) int32 — number of tokens per document
query_flat.npy       # (N_qtokens, dim) float32 — all query tokens concatenated
query_lengths.npy    # (N_queries,) int32 — number of tokens per query
qrels.json           # {"ground_truth": [[rel_doc_ids], ...]}
```

## Configuration

Default configuration (see `configs/default.yaml`):
| Parameter | Default | Description |
|-----------|---------|-------------|
| K | 32 | Number of k-means centroids per document |
| W' | 1,000 | FDE candidates |
| W | 200 | Chamfer rerank budget |
| R | 10 | FDE repetitions |
| B | 2 | FDE buckets |
| n_init | 1 | k-means initializations |
| max_iter | 50 | k-means iterations |

### Recommended K by modality
- **Text** (|D| < 200): K = 32
- **Visual** (|D| > 500): K ≥ 64
- **Visual with ρ > 2.5**: K ≥ 64 and W' = 3,000

## Practical Deployment Guide

1. **Compute ρ** with bootstrap CI from 200 sampled queries
2. If CI lower bound > 1.3 → deploy TCI
3. Use K = 32 (text) or K ≥ 64 (visual)
4. For high-ρ visual corpora, widen FDE pool to W' = 3,000
5. If improvement is below expectation, compute ρ_TCI; if > 1.0, increase K
